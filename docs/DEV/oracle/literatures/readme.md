
## HUST-OBC

### Wang Pengjie (王鹏杰) 

A researcher from Huazhong University of Science and Technology (HUST) who co-developed HUST-OBC, a large-scale open dataset and deep-learning research project for Oracle Bone Script (jiaguwen) recognition and decipherment.

Key Contributions to Oracle Bone Script Research

- [HUST-OBC Dataset](https://www.nature.com/articles/s41597-024-03807-x): Created a collection of 140,053 images of oracle bone characters (comprising 77,064 images across 1,588 deciphered characters and 62,989 images across 9,411 undeciphered characters) gathered from historical books, websites, and archives.
- [Puzzle Pieces Picker](https://arxiv.org/html/2406.03019v1) (P³): Co-authored research introducing an AI-driven method that breaks down ancient oracle bone inscriptions into foundational strokes and radicals, then uses Transformer models to reconstruct and analyze them into modern Chinese characters.
- [HUST-OBC](https://github.com/Pengjie-W/HUST-OBC) GitHub Repository open-sourced the project tools, datasets, and models.
