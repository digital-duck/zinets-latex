## 人人认得甲骨文


### intro

编者按：

甲骨文自1899年被发现至今，学者们已经整理出甲骨文单字4500多个。

在这些单字中，可识读的单字有一千多个。

本书选用九百多个常用单字（主要根据《甲骨文合集》、《新版殷墟甲骨文实用字典》、《甲骨文常用字字典》等）编纂成册。

希望有助初学者识读，让甲骨文也飞入寻常百姓家。



太和山居

2020年 1月12日
